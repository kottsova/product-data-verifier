# Product Data Verifier

Сервис для поиска, извлечения и проверки товарных характеристик по модели товара.

## Основной сценарий

Brand + Model + Article
→ Discover sources
→ Fetch sources
→ Match exact product
→ Extract attributes
→ Normalize
→ Validate
→ Result

## Результат

Attribute | Value | Status | Source | Evidence

Статусы:

- Confirmed
- Conflict
- Unresolved
